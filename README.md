# pstack-herdr

Private herdr-adapted fork of [cursor/plugins](https://github.com/cursor/plugins), containing only the pstack plugin.

`pstack/` is the Cursor plugin. `harness/pstack/` is the generated Claude Code copy the plugin installs from. After editing pstack sources, run `node scripts/generate-pstack-harness-trees.mjs` from the repository root and commit the result.
