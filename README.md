# pstack-herdr

Private herdr-adapted fork of [cursor/plugins](https://github.com/cursor/plugins), containing only the pstack plugin.

`pstack/` is the Cursor plugin. `harness/pstack/claude-code/` is the generated Claude Code copy. `harness/pstack/codex/` is the generated Codex copy. After editing pstack sources, run `node scripts/generate-pstack-harness-trees.mjs` from the repository root and commit the result.
